# 🌦️ Will It Rain On My Parade?

### Probabilistic Weather Prediction Using NASA Earth Observation Data

Will It Rain On My Parade? is a weather prediction application that uses **NASA Earth observation satellite data** to provide probabilistic weather predictions.

## 🎯 Project Overview

The project explores the use of satellite-based environmental data for weather prediction and presents the results through a web-based application.

Instead of providing only a simple yes/no prediction, the application focuses on **probabilistic weather forecasting**, helping users understand the likelihood of weather conditions.

## 🛰️ Data Source

The application works with **NASA Earth observation satellite data** as the primary data source for its weather prediction workflow.

The project uses environmental and atmospheric information obtained from NASA data resources to support its forecasting process.
